Folder Jump

Click a field and press the desired key combination. Modifiers (Ctrl, Shift, Alt) plus one key. Press Esc to cancel, Backspace to clear.

Undo last move: Ctrl+Z (⌘+Z on macOS) while the message list or folder pane of the main mail window has focus. This one is fixed — it is deliberately not a global shortcut, so Ctrl+Z keeps working in the composer and in text fields.

Shortcuts also editable via Add-ons Manager → Folder Jump → Manage Extension Shortcuts.
